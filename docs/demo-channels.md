# Demo Discord server layout

Create a club server (or use the class helping-hand server) with four desks. Channel names are how the cheap router hints a specialist when the message has no keywords.

| Channel | Specialist | What students do here |
|---|---|---|
| `#study-lab` | Tutor | Concepts, past-paper walkthroughs, `/quiz` |
| `#assignment-desk` | Writer | Outlines, citations, grammar, `/cv` — not full essays |
| `#campus-desk` | Campus | Deadlines, scholarships, hall notices. Admins `/kb add` official text |
| `#focus-room` | Focus | `/plan` exam dates, countdowns, reminders |

Captain still watches mentions and `/ask` everywhere in those channels.

Suggested extras (optional):

- `#crew-rules` — pin the academic-honesty note and pricing.
- `#admin-office` — treasurer confirms bKash/Nagad, then `/grant @user 30d`.

Handoff: a question in `#study-lab` is answered by **Tutor only**. Captain may post a one-liner (“Tutor has this.”) and then stay quiet.
